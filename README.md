# GymMate+ AI Powered Fitness Application

Requirements, system models and design for a mobile app that adapts workout programs to each user, built by a 9 person team of computer and industrial engineers.

## Overview

Most workout apps give everyone the same plan. GymMate+ adjusts the program based on how the user reports performance, fatigue and pain after each session, and adds trainer chat, progress tracking and badges that reward consistency. The project covered the full requirements and design phase of the system.

## What I did

- Designed the concept for a mobile app that adjusts workout programs from user feedback on performance, fatigue and pain, with trainer chat, progress tracking and badges for workout consistency
- Defined 285 requirements (175 functional and 110 non functional) in a 9 member interdisciplinary team, producing 94 use cases, 8 UI mock ups and 28 UML and ER diagrams
- Wrote use case specifications and non functional requirements with the Volere template, and built domain, component, package and detailed class diagrams for the application, data model and AI model

## Methods and tools

Requirements engineering, use case modeling, Volere template, UML (class, component, package and use case diagrams), ER modeling, UI mock ups.
